# Buffer Connector — заметка по аутентификации (OAuth)

Дата анализа: 2026-08-31

## Коротко: OAuth у Buffer формально есть, но коннектор работает по API-ключу

Buffer поддерживает OAuth2, но официально выдаёт **Access Token** напрямую в
панели разработчика (buffer.com/developers/apps) — без прохождения OAuth-танца.
Коннектор использует именно этот путь: пользователь копирует токен и вставляет
в панель Imperal.

## Как устроено подключение

В панели Imperal вводится **Buffer API Access Token** из
buffer.com/developers → My Apps → Create an App → Access Token.

## Что автоматизировано, а что — руками

| Этап | Как делается |
|---|---|
| Создание приложения в Buffer Developers | **РУКАМИ** — buffer.com/developers/apps |
| Копирование Access Token | **РУКАМИ** — токен показывается сразу на странице приложения |
| Валидация токена при подключении | **АВТОМАТИЧЕСКИ** — connect_buffer проверяет токен до сохранения |

## Почему не браузерный OAuth

Buffer сам рекомендует Access Token для личного использования своего
аккаунта (OAuth Authorization Code нужен только публичным приложениям,
работающим с чужими аккаунтами). Токен не протухает сам по себе — живёт,
пока пользователь не отзовёт его руками.

## Следствие для тестирования

Полный тест (каналы, посты, идеи) требует Buffer Access Token от реального
аккаунта с подключёнными соцсетями. Получить его можно за минуту в
buffer.com/developers — ручное действие владельца аккаунта.
